# Демо «Аким на 5 часов» — сценарий на 3 минуты

Один говорит, второй кликает. Все числа ниже — из движка (проверены тестами и в UI).

## Подготовка (за 10 минут до выхода)

- Запуск: `docker compose up --build -d --wait` (README, путь А) или без Docker — `cd web; npm ci; npm run build`, затем из `backend/` — `uvicorn app.main:app --port 8000` (путь Б); открыть http://localhost:8000. Без сети и ключа всё работает: записка строится по правилам или по шаблону.
- С ключом: `.env` с `OPENAI_API_KEY`, `OPENAI_MODEL` и `AI_CACHE=fallback` (живой LLM первым, кэш — страховка). Проверить `GET /api/health`: `provider=llm`, `model_status=ok`.
- Рекомендуемый режим показа — без ключа: сохранённый ответ агента из `data/cache/demo` приходит мгновенно (бейдж «кэш LLM», 10/10 чисел подтверждены); живой LLM (`AI_CACHE=fallback`) — только по просьбе жюри и при устойчивой сети.
- Браузер в полноэкранном режиме, 1280×720 или 1366×768 (макет один), светлая тема. Открыть `#/pult` — «Сброс» в шапке.
- На втором экране — README и терминал с `cd web; npm test` (142 passed) и `pytest -q backend/tests` (298 passed).

## Если что-то пошло не так

- LLM не ответил, завис или ключ недействителен — цепочка сама уходит в кэш или rules, ответ всегда HTTP 200. Говорить по тексту дальше, провайдер виден на бейдже записки.
- Бэкенд не запустился — `cd web; npm run dev`, http://localhost:5173: весь сценарий, кроме живого LLM, работает в браузере (бейдж «офлайн»).
- Вопрос «откуда числа» — показать галочку «офлайн-режим» и бейдж «N/N чисел подтверждены движком», затем `web/src/engine/engine.parity.test.ts` (71 кейс совпадает с Python до 1e-6).
- Вопрос «а если 3 меры» — число серое, пунктиром, подписано «предварительно · 3/5», без перцентиля: Score по ТЗ считается только для 5 решений по правилам.
