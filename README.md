# «Аким на 5 часов» — AI-симулятор управления городом

Команда **lowtap** · хакатон, спец-трек Astana Innovations.

Один виртуальный бюджет (100 у.е.), пять реальных районов Астаны, 14 мер, ровно пять решений.
Детерминированный движок считает **Astana Quality of Life Score**, AI-агент объясняет результат и
предлагает улучшения, каждое из которых пересчитано движком. Без API-ключа приложение работает полностью.

> Статус: в разработке. Запуск и сценарий проверки появятся здесь после первой точки сдачи (`v0.1-static`).

## Данные

- `data/districts.json`, `data/measures.json`, `data/rules.json` — датасет и правила из ТЗ (заморожены).
- `data/scenarios/*.json` — пресеты и невалидные наборы с ожидаемыми результатами (эталоны для тестов).
- `data/astana_districts.geojson` — границы районов, © OpenStreetMap contributors (ODbL).
